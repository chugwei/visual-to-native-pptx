# visual-to-native-pptx

## 目标

把一张参考图片还原成**一页真正可编辑的 PowerPoint**，而不是把原图贴上去。

可编辑的含义是：

1. 每个主要视觉元素（形状或图片）可以被单独点击、移动、改色、改线宽；
2. 每一处文字都是原生文本框，可以被单独选中、改内容、改字体字号颜色；
3. 几何元素是 PowerPoint 原生形状，而不是像素；
4. 独立实体的数量与参考图一致，每个实体保留独立编辑能力；单个实体优先使用一个完整原生形状。

**实现优先级**（遇到取舍时按此顺序决策）：

1. 整体布局和位置关系
2. 文字内容完整且可编辑
3. 视觉元素的可编辑性（形状优先）
4. 主要视觉元素完整
5. 元素尺寸与比例
6. 字体、字号、字重
7. 颜色
8. 微小装饰细节

宁可形状画得略有偏差，也不要用 PNG 精确贴图。本 skill 的核心价值是**可编辑性**，其次才是像素级相似。

---

## Phase 0 · 形状优先判定（最重要的一步）

动手之前，先对参考图中**每一个视觉对象**做实现方式判定。判定标准是：
**"纯色/渐变色 + 规则几何轮廓" → 必须用形状；"照片质感/繁复细节" → 才允许 PNG。**

### 对象完整性与形状选型（先于拆分绘制）

先识别参考图表达的完整实体及其数量，再选择形状。一个立方体的三个可见面属于同一个实体；三个堆叠立方体属于三个实体。结合外轮廓、接触边界、遮挡、重复结构及标注判断，不要把每个色面当作独立对象，也不要把不同实体当作一个对象。内部线可能是装饰线，也可能是实体接触边；图示与任务说明仍无法区分时，先询问用户。

对每个实体按以下顺序实现：**完整原生预设形状 → 单个原生 freeform → 必要的多形状组合**。先检查 PowerPoint 是否已有能表达整个对象的形状，并调整尺寸、旋转和 adjustment；不能仅因当前库未封装参数而认定原生形状不可用。

- **一个普通立方体：使用一个 `MSO_SHAPE.CUBE`**，调整尺寸及深度；禁止无理由用三个四边形拼成三个面。
- **N 个堆叠、并排或重复立方体：创建 N 个完整 `CUBE`**，分别设置位置、填充和遮挡顺序；可再 Group，但组内每个立方体须能分别选中、移动和改色。禁止用一个大立方体加横线、色带或描边模拟 N 个实体。
- **一个实体上的真实装饰线：保留一个完整实体，再添加装饰线**；不能仅凭内部线条就增加实体数量。
- **组合例外：**仅当完整原生形状或单个 freeform 无法满足参考图的明确要求（例如特殊透视、各面必须独立着色）时才拆面，并将属于同一实体的部件组成对象组。记录具体原因，不得仅为微小色差或省事拆面。`CUBE` 是二维立体示意形状，并不能表达任意三维视角。

减少的是单个对象不必要的部件，不能减少参考图中的独立实体。Group 只组织部件，既不能把三个面变成一个原生立方体，也不能补回缺少的实体。

### A 级 · 必须用 PowerPoint 原生形状（禁止导出 PNG）

- 线：直线、折线、虚线、点线、双线、分隔线、下划线
- 箭头：箭头、连接符、指示线、引线、坐标轴、网格线
- 四边形：矩形、正方形、圆角矩形、胶囊形、平行四边形、梯形
- 曲线形：圆形、椭圆、扇形、饼形、圆环、半圆
- 其他多边形：三角形、菱形、多边形、星形、十字形、L 形、箭头块
- 面：纯色/渐变色块、装饰块、遮罩块、半透明蒙层
- 容器底：卡片背景、标签底图、按钮底、气泡底、高亮底、进度条底与进度段
- 线框：边框、外框、内嵌描边框、裁切线、出血线
- 表格：表格线与表格底纹（优先原生表格，其次矩形 + 线段）
- 图表：柱状图、折线图、饼图、环形图等标准图表 → 优先 PowerPoint 原生图表对象；
  非标准图表 → 用矩形、扇形、折线、圆点等形状逐件拼出
- 立体示意形状：立方体、长方体、圆柱等 → 优先完整预设形状，如 `CUBE`、`CAN`
- 图标：先查完整预设形状；只有确由多个部件构成且无合适完整形状时，才拆成必要形状并 Group

### B 级 · 优先用形状，形状确实无法逼真还原时才允许 PNG

- 多色渐变、光效、柔和阴影 → 优先用形状的渐变填充 + 透明度 + 阴影效果实现；
  仅当光效过于复杂（高斯光晕、多层叠加）时才退化为 PNG
- 简单线性插画、几何风格插画 → 依次选择完整预设形状、单个 freeform、必要的多形状组合

### C 级 · 允许使用 PNG（仅限以下对象）

- 照片、人物图、产品实拍图、场景图
- 细节繁复的插画、手绘/水彩/油画质感图形
- 复杂纹理、材质贴图、噪点、大理石纹、木纹
- 细节繁复的 Logo、徽标、吉祥物（若 Logo 由简单几何构成，仍优先形状还原）
- 曲线细节过多、无法用有限形状拼出的图形

### 禁止行为（红线）

- 禁止把纯色/渐变的矩形、色块、线段、虚线、箭头、圆形、卡片底、标签底抠成 PNG
- 禁止以"省事""更像""形状不好对齐"为由，用图片替代本可还原的形状
- 禁止把多个本可独立拆分/独立绘制的元素合并成一张大 PNG
- 禁止把整张参考图、整块页面或大面积截图作为页面背景
- 禁止把文字栅格化进任何形状或 PNG

**自查红线：最终 PPT 中 PNG 数量通常不应超过 5 张。若超出，必须逐条说明每张 PNG 为何无法用形状还原。**

## Phase 1 · 视觉元素识别与重建

分析参考图中的全部视觉对象：照片、图标、Logo、插画、装饰图形、色块、标签底图、
卡片背景、几何形状、线段虚线、箭头连接符、图表非文字部分、阴影渐变、蒙层、边框、网格。

处理流程：

1. 先识别完整实体、数量及部件归属；对多形状实现的单个实体，记录不能使用完整形状的具体原因。再逐个记录属性：`x, y, w, h, z-order, rotation, fill, stroke, stroke_width,
   dash_style, corner_radius, alpha, gradient`。
2. 按 Phase 0 的 A/B/C 判定实现方式。
3. A 级、B 级对象 → 在 PPT 中用形状绘制，**不产生 PNG 文件**。
4. C 级对象 → 导出独立 PNG，要求：
   - 透明背景（PNG-24 带 alpha）
   - 保持原始长宽比，禁止拉伸变形
   - 裁剪边界贴合视觉元素，不保留大面积空白透明区
   - PNG 中不得含文字；若元素内部原有文字，先从图像中去除，再在 PPT 中叠加文本框
   - 一个独立视觉对象对应一个 PNG，禁止合并
5. 纯色/渐变页面背景不导出 PNG，直接设为页面背景或铺底矩形形状。

## Phase 2 · 文字全部重建为文本框

**禁止把文字作为图片的一部分放入 PPT。**

识别图中全部文字，逐条重建为 PowerPoint 原生文本框，尽量匹配：
文本内容、字体、字号、字重、颜色、行距、字符间距、对齐、换行、文本框宽高、X/Y 坐标、
与其他元素的相对位置。

规则：

- 原图中视觉上独立的文字区域 = 独立文本框。
- 标题、副标题、正文、标签、数字、页码、注释、图例、坐标刻度等，禁止无意义合并成大文本框。
- 文本框默认**无填充、无边框**。若原图文字带底色块或边框，必须用独立形状绘制并置于文字下方，
  不得作为文本框填充蒙混，也不得把底色与文字合成一张图。
- 字体缺失时的替代顺序：
  1. 找视觉特征最接近的已安装字体；
  2. 保持风格、粗细、宽度尽量一致；
  3. 用字号、字距、行距和文本框尺寸逼近。
- 不得因字体不确定而把文字转成图片。

---

## Phase 3 · 坐标映射

建立统一映射：**图片像素坐标 → PPT 页面坐标**。

所有形状、PNG、文本框按原图的 X、Y、宽、高、层级、对齐、间距重新放置，保持原始比例，
禁止凭感觉重新排版。

重点核对：

- 左右边距、上下边距
- 标题基线、文本基线对齐
- 元素间距、卡片尺寸、图片尺寸、文本框宽度
- 文本换行位置
- 图标与文字的对齐
- 前后遮挡关系（z-order）
- 形状的旋转角、圆角半径、线宽、虚线节奏

页面比例：若参考图不是 16:9，不要强转 16:9，选择最接近的页面尺寸（4:3、3:2、1:1、竖版），
必要时自定义页面宽高（EMU）。

## Phase 4 · 图层与对象类型

最终 PPT 由四类对象组合：

| 类型 | 实现方式 |
|---|---|
| 几何与装饰元素 | PowerPoint 原生形状（矩形、圆、线、箭头、连接符、freeform、原生图表、组合形状） |
| 复杂视觉元素 | 独立透明 PNG（仅限 Phase 0 的 C 级） |
| 文字元素 | PowerPoint 原生文本框 |
| 纯色/渐变背景 | 页面背景或铺底矩形形状 |

禁止：整页截图铺底、大面积截图覆盖、文字栅格化、全部内容合并为一张图、用 PNG 代替形状、
用图片文字代替文本框。

最终用户应能：单独点击/移动每个主要元素；单独修改形状填充、描边、线宽、虚线、圆角、阴影；
单独修改文字内容与样式；调整大小、位置与层级。

## Phase 5 · 形状还原技术规范

使用 python-pptx（或等效方式）时遵守：

- **形状类型**：先查能表达整个实体的预设形状。`MSO_SHAPE`（`CUBE`、`CAN`、`ROUNDED_RECTANGLE`、`OVAL`、`ISOSCELES_TRIANGLE`、
  `RIGHT_ARROW`、`CHEVRON`、`DIAMOND`、`PIE`、`BLOCK_ARC` 等）、`Connector`（直线/折线）、
  `FreeformBuilder`（不规则轮廓）。
- **圆角**：圆角矩形必须用 adjustment 还原，`adj ≈ 圆角半径 ÷ min(w, h)`，禁止一律用默认值。
- **线段与虚线**：还原线宽(pt)、颜色、虚线样式（solid / dash / roundDot / dashDot / longDash）
  与虚线节奏。禁止用"一排小矩形"冒充虚线，禁止用 PNG。
- **箭头与连接符**：还原端点箭头样式（begin/end arrow type）与端点粗细。
- **渐变填充**：还原类型（线性/射线）、角度、渐变光圈（颜色 + 位置 + 透明度）。
- **透明度**：填充与描边的 alpha 必须还原（必要时写入 `a:alpha`）；半透明蒙层 = 带 alpha 的矩形。
- **阴影**：优先形状自带阴影（outer shadow / soft edge），禁止用模糊 PNG 代替。
- **旋转与翻转**：精确还原 `rotation`、`flipH`、`flipV`。
- **描边与填充分离**：用形状自带 `line` 属性画边框，禁止叠加第二个形状当边框。
- **立方体**：使用 `slide.shapes.add_shape(MSO_SHAPE.CUBE, x, y, w, h)`，通过 `shape.adjustments` 调整深度。N 个独立立方体创建 N 个完整形状，线条不能代替缺少的实体。
- **组合**：确需多部件的单个对象按对象 Group；多个独立实体可再建立外层组，保留组内各实体的独立编辑能力。
- **图表**：标准图表插入原生 Chart 并还原系列颜色、网格线、标签；非标准图表用形状拼。
- **文本框**：`word_wrap=True`、autofit 关闭、边距归零、垂直对齐显式指定、
  段落行距（exact/at least）与字符间距（`spc`）按原图设置。
- **取色**：所有填充、描边、文字颜色必须从原图对应像素采样准确 RGB/HEX，禁止凭印象取色。

## Phase 6 · 输出

最终只输出：

- 全部拆分得到的 `.png`（仅 C 级对象）
- 一个最终 `.pptx`

PNG 与 PPTX **直接放在最终输出位置，不要创建子文件夹**。命名清晰稳定，例如：
`element_01.png`、`hero_image.png`、`photo_01.png`、`logo.png`、`complex_illustration.png`。

禁止输出：临时图片、Debug 图、OCR 中间结果、测试文件、多个版本 PPTX、Python 缓存、
中间处理目录。最终目录只保留交付文件。

## Phase 7 · 渲染检查（必做）

PPT 生成后**不要立即结束**。必须把 PPT 页面重新渲染为图片，与原图逐项对比：

1. 页面整体比例是否一致
2. 元素位置是否偏移
3. 形状尺寸、圆角、线宽、虚线样式是否一致
4. 形状与图片是否拉伸变形
5. 文本是否错误换行
6. 文本框是否过宽/过窄
7. 字号是否明显不匹配
8. 颜色（填充、描边、文字）是否接近
9. 元素间距是否一致
10. 是否有元素遗漏
11. 是否有文字遗漏
12. 图层遮挡关系是否正确
13. 是否把文字留在 PNG 或形状里
14. **是否把本可用形状还原的元素做成了 PNG**（逐个复查，若有则改为形状并重渲染）
15. **是否因"图片代替形状"出现边缘模糊、像素感、与周围形状风格不统一**

**还须检查实际对象结构，渲染相似不能证明实体可独立编辑：**通过编辑器、python-pptx 或解包 PPTX 检查形状类型、数量和组内对象，与 Phase 1 识别的实体对应。单个普通立方体应对应一个 `a:prstGeom prst="cube"`；三个堆叠立方体应对应三个完整立方体对象。组合例外须核对具体原因及各实体分组；不能仅检查全页形状总数。确认每个实体可独立选中、移动和改色。

发现差异：**改 PPT → 再渲染 → 再比对**，直到整体布局与主要细节一致。
禁止仅凭代码坐标宣告完成。至少完整执行一次：`生成 → 渲染 → 对比 → 修正`。

## 验收清单

结束前逐项自查：

- [ ] 没有使用整张原图作为页面背景
- [ ] 所有线段、虚线、箭头、矩形、圆角矩形、圆形、色块、卡片底、标签底、进度条、边框、网格均为原生形状
- [ ] 单个实体优先使用完整原生形状，未无理由拆面；必要组合已按对象分组并说明原因
- [ ] 独立实体数量与参考图一致，未用一个大形状加分隔线模拟多个实体
- [ ] 已检查实际形状类型、数量及分组，每个独立实体可分别选中、移动和改色
- [ ] 所有标准图表为原生图表或形状拼出
- [ ] 仅照片、复杂插画、纹理、复杂 Logo 等无法形状化的对象使用 PNG
- [ ] PNG 均为透明背景，比例正确，无拉伸
- [ ] PNG 不包含本可重建的文字
- [ ] 所有文字为可编辑文本框，字体字号颜色接近原图
- [ ] 文字的底色块、边框为独立形状，而非文本框填充或图片
- [ ] 页面尺寸与参考图比例一致或高度接近
- [ ] 整体布局与文本换行接近原图
- [ ] 元素层级（z-order）正确
- [ ] 形状的圆角、线宽、虚线样式、渐变、透明度已尽量还原
- [ ] 无明显遗漏（元素与文字）
- [ ] 已渲染检查并与原图逐项对比
- [ ] 已根据渲染结果修正明显偏差
- [ ] 已复查"用 PNG 代替形状"的情况并改正
- [ ] 最终只保留交付用 PNG 与一个 PPTX

**全部满足才算完成。** 若个别元素或字体确实无法准确还原，不得用整页截图规避，
应选择视觉上最接近的替代方案（优先形状近似），并保证文字可编辑、元素独立、几何元素为原生形状。

## 附录 · 常见判定速查

| 原图中的元素 | 实现方式 |
|---|---|
| 细直线、分隔线、虚线、网格 | Connector / 直线形状 + dash style |
| 实心箭头、指示块 | `RIGHT_ARROW` / `CHEVRON` / freeform |
| 卡片、标签、按钮、高亮底 | 矩形 / 圆角矩形（adj 还原圆角） |
| 圆点、徽标底、头像框 | `OVAL`（内容若是照片则为 PNG + 形状边框） |
| 进度条、滑块 | 两个矩形（底 + 进度段） |
| 半透明遮罩、渐变背景 | 矩形 + alpha / gradient fill |
| 柱状图、折线图、饼图 | 原生 Chart，或矩形/扇形/折线拼 |
| 单个普通立方体 / 长方体示意 | 一个 `CUBE`，调整尺寸及深度；特殊视角按 Phase 0 判定 |
